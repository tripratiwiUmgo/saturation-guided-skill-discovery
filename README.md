# Saturation-Guided Skill Discovery Framework

This repository contains the code and derived data used in the study:

"A Saturation-Guided Framework for Determining Data Sufficiency in Skill Extraction from Online Job Advertisements"

## Overview
The repository implements an order-robust, saturation-guided pipeline for determining data sufficiency in skill extraction from online job advertisements. The method operationalizes informational convergence using Marginal Discovery Rate (MDR), coverage gating (n80), and persistence constraints.

## Repository Structure
- `code/`: Python scripts for skill extraction, discovery curve construction, saturation detection, randomized permutations, and result generation.
- `data/`: Derived, sentence-level datasets and summary tables used in the experiments.
- `figures/`: Figures generated by the analysis scripts.

## Data Availability
Raw job advertisement texts from LinkedIn and JobStreet cannot be redistributed due to platform terms of service. To ensure reproducibility, we provide derived sentence-level datasets containing extracted skill sets and discovery metrics sufficient to reproduce all reported analyses, tables, and figures.

## Reproducibility
To reproduce the main results:
1. Install dependencies from `requirements.txt`
2. Run scripts in the following order:
   - `extract_skills.py`
   - `compute_discovery_curves.py`
   - `saturation_detection.py`
   - `randomized_permutations.py`
   - `generate_tables.py`
   - `generate_figures.py`
